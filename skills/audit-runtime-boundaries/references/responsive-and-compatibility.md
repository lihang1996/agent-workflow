# Responsive and compatibility

Build the matrix from the contract. At minimum for a public web UI, consider phone, tablet, compact
desktop and wide desktop. Check page-level horizontal overflow, clipped controls, fixed/sticky
overlap, readable line length, table behavior and virtual keyboard interactions.

Run each required browser engine or mark it unverified. Chrome-derived evidence does not prove
Safari/WebKit or Firefox behavior. Record exact engine, version, viewport, device scale and locale.

Use stable seed data and deterministic routes for screenshots. A screenshot alone does not prove
keyboard behavior, HTTP contracts or dynamic state transitions.
