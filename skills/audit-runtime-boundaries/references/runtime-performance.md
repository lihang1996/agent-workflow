# Runtime performance

Use contract budgets rather than universal numbers. Capture:

- production build asset sizes and route chunks;
- image intrinsic dimensions, lazy/eager policy and layout stability;
- critical request count and caching;
- server latency for representative and boundary inputs;
- timeouts, retry behavior and error observability;
- browser performance metrics when tooling is available.

Do not claim a score that was not measured. Distinguish local measurements from production-like
measurements and keep raw report artifacts addressable.
