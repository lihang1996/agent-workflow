# Web accessibility runtime checks

- Navigate all interactive controls by keyboard in logical order.
- Verify visible focus appears only when appropriate and is not clipped.
- Open each modal/menu, confirm focus entry, containment, Escape behavior and restoration.
- Check labels, names, descriptions, heading order, landmarks and current-page semantics.
- Verify errors are associated with fields and announced.
- Check 200% zoom, text reflow and touch target usability.
- Exercise loading, empty, error and permission states.

Automated scans find only a subset of issues. Store both scan output and manual keyboard evidence.
Do not claim WCAG conformance from a zero-violation automated result.
